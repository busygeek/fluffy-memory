# Mock REST API

A comprehensive Mock REST API built with Spring Boot 3.2 and Java 21, featuring flexible response handling, file-based storage, JWT authentication, and comprehensive Swagger documentation.

## 🚀 Features

- **Generic CRUD Operations** - Create, Read, Update, Delete for any collection
- **Flexible Storage** - Individual JSON files or collection-based storage
- **Custom Response Handling** - Store and retrieve custom responses
- **Error Simulation** - Endpoints for testing different HTTP status codes
- **JWT Authentication** - Static token-based security
- **Swagger Documentation** - Interactive API documentation
- **File-Based Storage** - No database required, uses JSON files
- **Lombok Integration** - Clean, concise code
- **Comprehensive Logging** - Detailed operation logs

## 📋 Prerequisites

- Java 21 or higher
- Maven 3.6 or higher

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd mock-rest-api
   ```

2. **Build the project**
   ```bash
   mvn clean install
   ```

3. **Run the application**
   ```bash
   mvn spring-boot:run
   ```

4. **Access the application**
   - API Base URL: `http://localhost:8080`
   - Swagger UI: `http://localhost:8080/swagger-ui.html`
   - OpenAPI Docs: `http://localhost:8080/api-docs`

## 🔐 Authentication

The API uses JWT token authentication with a static token for testing purposes.

### Getting the JWT Token

```bash
GET /api/auth/token
```

**Response:**
```json
{
  "status": 200,
  "message": "JWT token retrieved successfully",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJtb2NrLXVzZXIiLCJuYW1lIjoiTW9jayBBUEkgVXNlciIsImlhdCI6MTUxNjIzOTAyMiwiZXhwIjoxOTk5OTk5OTk5fQ.Lkylg3oDcCPOSeC40QLdwO3aDFTh6YQScZRLWJPSyrc",
    "type": "Bearer",
    "usage": "Add to Authorization header as: Bearer <token>"
  }

```

### Using the Token

Add the token to your requests:

```bash
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiJtb2NrLXVzZXIiLCJuYW1lIjoiTW9jayBBUEkgVXNlciIsImlhdCI6MTUxNjIzOTAyMiwiZXhwIjoxOTk5OTk5OTk5fQ.Lkylg3oDcCPOSeC40QLdwO3aDFTh6YQScZRLWJPSyrc
```

### Disabling Security (for testing)

To disable JWT authentication, set in `application.yml`:

```yaml
mock-api:
  security:
    enabled: false
```

## 📁 Directory Structure

The API creates a `mock-data` directory with the following structure:

```
mock-data/
├── users/                     # Collection directory
│   ├── data.json             # Collection-wide data
│   ├── user1.json           # Individual item files
│   └── user2.json
├── products/
│   ├── data.json
│   └── product1.json
└── custom_response_key1.json  # Custom responses
```
